# CMS Setup — Sura New International

The site includes a Decap CMS interface under `/admin/` and editable JSON content under `/content/`.

### Production setup
1. Put the website in a Git repository.
2. Connect the repository to the chosen static host.
3. Configure CMS authentication (Git Gateway/Identity or another supported provider).
4. Keep `admin/config.yml` in the repository root structure.
5. Open `/admin/` to edit the five language files and site settings.
6. Connect the contact form to the company mailbox or CRM before launch.

No passwords, API keys or private credentials are stored in this package.
