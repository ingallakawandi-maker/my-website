# Sura New International — Global Corporate Website

Multilingual corporate website for Sura New International.

Languages: Arabic (🇸🇾 / RTL), English, French, Italian, German.

## Structure
- Premium responsive corporate front-end
- Content separated by language in `content/*.json`
- Decap/Netlify CMS-ready admin at `/admin/`
- Logo in `assets/sura-logo.png`
- Static hosting compatible

## CMS
The admin interface is prepared for Decap CMS. To enable authenticated editing in production, connect the repository to a Git provider and configure the selected CMS authentication method (for example Netlify Identity/Git Gateway or an equivalent supported workflow). The current package does not contain private credentials or secrets.

## Deployment
The package can be hosted on Netlify, Vercel, Cloudflare Pages, or conventional static hosting. DNS can then be pointed to `www.sura-newinternational.com`.

## Important
The contact form is presentation-ready and should be connected to a verified mailbox/CRM endpoint before production launch.
